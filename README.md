# Julissa Lescano — Portafolio Web

Portafolio web profesional de Julissa Lescano, estudiante de Ingeniería de Software. Este proyecto presenta una selección de habilidades, proyectos destacados y experiencia en desarrollo.

## Características

*   **Diseño Moderno:** Interfaz limpia con soporte nativo para tema claro y oscuro (Dark/Light mode).
*   **Totalmente Responsivo:** Adaptable a todo tipo de dispositivos (Móviles, Tablets, Escritorio).
*   **Sistema de Filtros:** Visualización interactiva de proyectos organizados por categorías (Full-Stack, Data Analytics, Machine Learning).
*   **Design System Propio:** Utiliza un sistema de diseño estructurado basado en variables y tokens de CSS.

##  Estructura del Proyecto

*   `index.html`: Estructura principal y contenido semántico de la página.
*   `css/`
    *   `variables.css`: Design System, tokens de color, tipografía y espaciado.
    *   `styles.css`: Reglas de estilos globales y componentes de la UI.
*   `js/`
    *   `main.js`: Lógica interactiva (Toggle de tema, Modal de proyectos, Filtros).
*   `assets/`: Imágenes y recursos visuales de los proyectos.

## Proyectos Destacados

1.  **GUIOSAD — Evaluación SWOT & FLOSS** (Full-Stack)  
    Sistema transaccional y asistido por IA para auditar y evaluar la viabilidad de adopción de software libre empresarial.
2.  **Agrobio Analytics — Dashboard Agroclimático** (Data Analytics)  
    Plataforma interactiva para el monitoreo de variables agroclimáticas usando Python, Streamlit, Plotly y PostgreSQL.
3.  **Bike Rental Prediction** (Machine Learning)  
    Red Neuronal Artificial para la predicción de demanda de bicicletas compartidas, integrada con Flask API.
